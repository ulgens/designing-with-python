# Designing with Python: Programming for a Visual Context

Study notes for https://www.domestika.org/en/courses/4307-designing-with-python-programming-for-a-visual-context

## Setup & Install

> [!IMPORTANT]
> `py5` requires Java: https://py5coding.org/index.html#installation
>
> Under macOS, installing `openjdk` from brew provides a working Java setup. For other platforms, please check the py5 docs.

The project uses uv as Python package & env manager. You can interact with it using uv as the interface.
